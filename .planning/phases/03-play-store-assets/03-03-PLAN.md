    What this checkpoint produces:
    No code is involved — this is a manual Canva design step. D-10 confirms the in-app launcher mipmap icons are out of scope; this produces only the 512x512 Play Console upload asset.
  
  

    Steps to perform:
    In Canva:
    1. Create a design with custom dimensions exactly 512 x 512 px — a FULL SQUARE artboard.
    2. Background: solid `#060D1A`. Fill the entire square — do NOT round the corners and do NOT add a drop shadow (Google Play applies a 30% corner radius and shadows dynamically; pre-applying causes double-rounding artifacts).
    3. Center artwork: a Lumi character (glowing gold face — reference the Lumi SVG) or a mountain/summit motif, using gold `#D4A55A` as the primary accent.
    4. Keep the artwork comfortably inside the square (leave ~10% padding) so dynamic corner-rounding does not clip it.
    5. Export as PNG, 32-bit (PNG with alpha — for the icon, alpha support IS required, unlike screenshots). Save as `assets/play-store/icon-512.png`.

    After export, run from `C:\Users\hamou\ai-fluent`:
    `magick identify -verbose assets\play-store\icon-512.png`
    Confirm: Geometry `512x512`, and the image is a PNG. Confirm file size under 1024 KB.
  
  </action>
