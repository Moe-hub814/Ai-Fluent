<objective>
Capture the 5 required Play Store phone screenshots from the physical Android device running the Phase 2 release build, and convert each to RGB PNG (no alpha channel) so they meet Google Play's 24-bit PNG requirement.

Purpose: Screenshots are the highest-value visual asset on a Play Store listing and must come from the real release build to render accurately. RGBA output from `adb screencap` is rejected by Play Console — alpha removal is mandatory.
Output: 5 raw screenshots + 5 RGB-converted screenshots at 1080x1920px in `assets/play-store/screenshots/`.
</objective>

  </read_first>
  <action>
    Strip the alpha channel from every raw screenshot per D-02. Run this PowerShell batch from `C:\Users\hamou\ai-fluent`:

    ```powershell
    Get-ChildItem "assets\play-store\screenshots\*-raw.png" | ForEach-Object {
        $rgb = $_.FullName -replace '-raw\.png', '-rgb.png'
        magick $_.FullName -alpha off $rgb
        Write-Host "Converted: $($_.Name)"
    }
    ```

    Then verify each output. For every `*-rgb.png`, run `magick identify -verbose <file>` and confirm: dimensions `1080x1920`, and the `Type` line is NOT `TrueColorAlpha` (must be `TrueColor` or `sRGB` with no alpha). Equivalently, `magick identify -format "%[channels]" <file>` must print `srgb` (3 channels) — NOT `srgba`.
  </action>
