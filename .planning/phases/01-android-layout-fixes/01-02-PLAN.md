<objective>
Fix the "Good afternoon, AI" bug (LAYOUT-03). Replace the current 2-step fallback chain on the user's first name with the 3-step chain specified by D-05, and thread the `user` object as a prop into both `WorldMap` and `LocView` so that `user?.email?.split("@")[0]` can actually resolve. Without the prop threading, the new fallback expression would evaluate `undefined?.email` and produce silent dead code.

Purpose: The existing fallback `profile?.display_name?.split(" ")[0]||"Climber"` has two failure modes — (a) if display_name is a whitespace-only string it passes the optional-chain but produces an empty first token, which still renders as the greeting, and (b) if display_name is literally "AI" or "AI Fluent" from a historical onboarding run, it renders that instead of the expected name. D-05 fixes (a) with `.trim()` and adds a middle fallback to `user.email.split("@")[0]` so that even if display_name ends up unusable, the user still sees their own email prefix instead of the hardcoded literal.

Output: `src/App.jsx` with two signature edits (WorldMap and LocView add `user` to destructured props), two call-site edits (AIFluent render passes `user={user}` to both components), and two fallback-expression edits (WorldMap line ~711 and LocView line ~904 use the 3-step chain).
</objective>
