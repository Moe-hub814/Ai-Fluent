Purpose: D-07 requires `android.backgroundColor: "#060D1A"` in `capacitor.config.json` to prevent the white-flash-then-dark transition during Android cold start. The color matches the top stop of the dark-mode world-map gradient (`src/App.jsx` line ~725: `linear-gradient(180deg, #060D1A 0%, ...`), so the transition from native splash to web layer is seamless. After adding the key, `npx cap sync android` must run to propagate the JSON into `android/app/src/main/assets/capacitor.config.json` — without this sync, the AAB build will still use the un-patched config.

Plans 01 and 02 modified JavaScript only. Their effects cannot be observed on an Android device until after a `npm run build && npx cap sync android` cycle. This plan is the point where those code changes, plus the config change below, are physically validated on hardware.

Output: Two config files with matching `android.backgroundColor` entries, a device-install artifact (APK or Gradle `installDebug` run), and a documented human confirmation that all four LAYOUT requirements are visually satisfied.
